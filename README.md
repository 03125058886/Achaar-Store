# Achaar Ghar - Static Store

Static achaar shop for Pakistan. Orders go to WhatsApp via checkout form.

- `index.html` - page
- `css/style.css`, `css/animations.css` - design + animations
- `js/products.js` - store settings (WhatsApp number, delivery) + product list
- `js/app.js` - cart, quick view, checkout -> WhatsApp
- `js/animations.js` - scroll reveal, fly-to-cart, counters
- `images/` - product photos (Pexels, free license)

Later: replace `products.js` with an API/database.
